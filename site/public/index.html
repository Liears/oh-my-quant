04 / GOOD TO KNOW

开始之前。

这是一个在线交易平台吗？+

WhyJ Quant 是安装在本机的量化研究终端。这是它的产品介绍与交互演示页面；网页不连接证券账户，也不执行交易。

需要自己配置模型和数据源吗？+

需要。在 /config 中选择模型连接与适合研究市场的数据源。部分数据源需要 API key，AKShare 路径需要本机 Python 环境和相应依赖。模型和数据服务费用由各提供方收取。

研究数据保存在哪里？+

配置、研究会话与报告保存在本地工作区。分析时会向你选择的模型和数据提供方发送必要请求；本地存储不等于所有计算都离线。官网仅在浏览器保存演示偏好。

如何反馈或参与开发？+

项目采用 MIT 许可证。你可以在 GitHub 阅读代码、提出问题或提交改进。界面能力以所安装版本和配置为准。
